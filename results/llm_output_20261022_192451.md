## TEST PLAN
Цель тестирования: Проверить корректность работы функциональности корзины интернет-магазина.

Объект тестирования: Корзина интернет-магазина

Стратегия: Комбинированная стратегия, включающая функциональное, регрессионное и негативное тестирование.

Критерии входа:
- Функционал корзины должен быть реализован.
- Система должна быть настроена для работы с тестовыми данными.

Критерии выхода:
- Все функции корзины работают согласно требованиям.
- Корректность обработки граничных значений и ошибок подтверждена.
- Отсутствие критических дефектов, влияющих на работу корзины.

Тестовое окружение и тестовые данные:
- Тестовый интернет-магазин с функциональностью корзины.
- Тестовые товары для добавления в корзину.
- Пользователи для выполнения действий (добавление, изменение, удаление товаров).
